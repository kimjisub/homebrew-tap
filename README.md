# kimjisub/homebrew-tap

Homebrew casks for [kimjisub](https://github.com/kimjisub)'s apps.

```sh
brew install --cask kimjisub/tap/toolsmith
```

| Cask | App |
|---|---|
| `toolsmith` | [Toolsmith](https://github.com/kimjisub/toolsmith), a menu bar utility you assemble from the tools you need |

Casks are updated automatically by each app's release workflow.
